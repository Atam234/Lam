# OmniMode (Android)

Multi-model AI Modes runner built with Kotlin, Jetpack Compose, Firebase AI Logic, and streaming REST/SSE support for custom AI APIs.

## Features
- **AI Modes**: Ready-to-run modes (Smart Assistant, Code Architect, TL;DR Summarizer, Polyglot Translator, Idea & Prompt Lab, Deep Analyst) plus custom user-created system-prompt modes.
- **Built-in Gemini (No API Key Required)**: Powered by Firebase AI Logic (`gemini-3.8-flash`, `gemini-3.5-flash-lite`, `gemini-4-argon`) with App Check attestation.
- **Any AI Model via API**: Configure OpenRouter, OpenAI, Anthropic Claude, Groq, DeepSeek, Ollama/local servers, or any custom OpenAI-compatible / Anthropic / Gemini REST endpoint and model ID with real-time SSE streaming and live connection testing.
- **Session History**: Save and reopen past AI mode sessions locally on-device.
